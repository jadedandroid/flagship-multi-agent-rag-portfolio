Flagship Runtime

Deterministic Multi-Stage RAG

A browser-executable, extractive RAG implementation: it plans a bounded lookup, combines lexical retrieval signals, validates exact source spans, and refuses unsupported questions. It does not call an LLM or use official NYC records.

JavaScript · TF-IDF · BM25 · RRF
How a question moves through the system query → plan → retrieve → validate → critique → answer
1

Planner

Classifies intent, splits bounded compound queries, and selects a retrieval budget from two to six chunks.

deterministic JS

2

Retriever

Runs local TF-IDF cosine and BM25-style keyword ranking, then combines ranked results with reciprocal-rank fusion.

local hybrid RRF

3

Validator

Checks payload shape, source membership, and exact quote-to-claim equality. Unsupported or forged spans fail closed.

runtime schema checks

4

Critic

Surfaces conflicting positions and archived dates, and flags instruction-like retrieved text as untrusted data.

metadata + rule checks

Exact-span extraction

Responses quote retrieved fixture text directly. There is no generative model or paraphrasing step in this implementation.

Adversarial checks execute

Twenty-seven local assertions cover retrieval, conflicts, injection signals, refusal behavior, schema shape, and forged citations.

  • Extractive answers only; no model generation, embeddings service, database, or network retrieval.
